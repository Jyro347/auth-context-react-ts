# Студия — AuthContext

Контрольная точка 2.5 по React. Учебный вход по имени на React 18, TypeScript и Vite.

## Запуск

```bash
npm ci
npm run dev
```

Команда `npm run build` проверяет типы и собирает проект.

## Проверка

1. Введи имя и нажми «Войти». Имя появляется в кабинете и в подписи к портрету, а в шапке показывается активная сессия.
2. Обнови страницу. `AuthProvider` восстановит пользователя из `localStorage` через `useEffect`.
3. Нажми «Выйти из аккаунта» и обнови страницу. Останется гостевой режим.
4. Перемещай курсор от левого края окна к правому. Портрет переключает ракурсы.

`useAuth` используется в трёх компонентах на разной глубине: `App`, `AccessCard` и `SessionDetails` внутри `Portrait`. Промежуточные компоненты не передают данные авторизации через props.
